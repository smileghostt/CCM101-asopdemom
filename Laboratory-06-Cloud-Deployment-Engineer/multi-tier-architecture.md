A multi-tier architecture is a design model for client-servers in which parts of the server is segregated into tiers.

# Web/Application Tier
The web/application tier is the tier in which the server itself can be seen or functions. This tier usually serves as the user-facing presentation of the server.

# Database Tier
THe database tier is the tier in which the server's database exists within. These usually serve to store data like accounts and information from accounts.

# Why separate these?
Having these separate allows not only for more organization but also security. It is also more scalable and maintainable in the long run.

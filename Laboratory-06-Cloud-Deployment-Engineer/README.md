# Mission Overview
Our mission involves dealing with docker-compose and IaC (Infrastructure as Code). While within the last missions it is more focused on singular containers, this one focuses on ensuring that you are able to deploy multiple containers relatively easily.
# Objectives
The objective is to be able to modify and understand the docker-compose.yaml file. Not only that, but also to be able to deploy a multi-tier system, with the one being shown being Nextcloud + MariaDB. This ensures we have a simple example to work with. Afterwards, we should be able to explain and understand Infrastructure as Code.

# Commands Executed
- `mkdir` - makes a directory, simple as that.
- `cd` - enters a specified directory.
- `nano` - a text editor. This can be used to make a new file and immediately edit it.
- `docker-compose up` - builds containers based on the docker-compose.yaml file.
- `docker-compose ps` - lists active containers, different from `docker ps` as it targets the containers within your YAML file.

# Skills Learned
Most of the skills that were learnt here is more on handling the docker-compose.yaml file, which means understanding how to treat containers as code.

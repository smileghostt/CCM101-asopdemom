# Linux Commands Used 🗣️🔥
This is a list of the linux commands that have been used within the activity! There are a huge set of these, so I will try to do what I can remember!

- `sudo`: not a command on itself, used before actual commands for superuser access
- `useradd`: creates a user, usually formatted like `useradd [flag] username`
- `passwd`: allows for adding/changing passwords for users. formatted like `passwd user`
- `su`: substitute user. can be used to switch users, formatted like `su - user`
    - user can be blank to set to root
- `bash`: creates bash session
- `ls`: shows the contents of the directory
    - this has multiple flags and can list the contents of other directories
- `mkdir`: make a directory.
    - this can be used to make multiple directories by just adding more, example being `mkdir dir1 dir2 dir3..`
- `cd`: change directory
- `touch`: create a file, formatted like `touch filename.ext`
    - this one has flags as well, plenty of these commands have their own flags, man files list these
- `nano`: not present in every distribution, a popular commandline text editor
    - in other distros (or if made from the ground up via Arch Linux for example), other text editors may be used. `nano` can be substituted for `vim`, whether its from the original Vim or NeoVim
- `cat`: short for concatenate. can be used to view, combine, or create text files
- `lsb_release`: linux standard base release. used to check the linux distribution
- `uname`: unix name, provides system information, especially needed when checking the kernel version
- `lscpu`: list CPU information. provides the architecture of the CPU
- `free`: provides information regarding system memory and usage
- `df`: disk free, provides information regarding disk usage

> **REMEMBER!** plenty of these commands have their own respective flags, man files may provide more information regarding how to use these commands, and most commands do not go without one. It is always available to provide help

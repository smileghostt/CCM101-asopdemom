## Mission Overview 🚀
The following mission of this laboratory activity is to be able to differentiate VMs and containers. Not only that, be able to use and understand the usage of containers. This also means being able to use docker, create containers, check containers, and even remove containers all in a CLI.
## Objectives 📋
- Research VMs and Containers
- Utilize Docker
- Execute fundamental Docker commands
- Handle a containerized application
## Docker Commands Executed 🖥️
- `docker --version` - this checks the version of docker that is installed in the device.
- `docker run` - allows you to create and/or run a docker container
- `docker ps` - lists docker containers, can be used with flag `-a` (all) to list every available container
- `docker stop` - stops an active container
- `docker rm` - removes an inactive container. Can be used to remove active container by adding the flag `-f` for force

# Overview 🔍
AWS or Amazon Web Service is a cloud platform that offers infrastructure for web applications and websites. Not only that, but it is able to provide a platform made for you to run your web applications and/or websites. All of this is done in order for you to be able to manage your platforms no matter if you are a small business or an enterprise, and with a wide variety of what type of web app or website is to be hosted.
## Global Infrastructure 🌐
AWS has a massive infrastructure, spanning throughout the globe, with 39 geographic regions and 124 availability zones as of writing this. Due to AWS having established early on, it has managed to be available within almost anywhere in the world. AWS also has Edge Locations and CloudFront POPs. This allows for areas that, while far from the settled infrastructure within the region, to have low latency. Theres over 750 CloudFront POPs all over the world.
## Cloud Management Console 🎛️
The cloud management console of AWS provides a centralized area to check your services. The homepage in particular of the console provides the security of your services, the cost and usage of said services, the health of your services, and any of AWS services you recently visited in case you want to return to those services for any changes. The console also allows you to handle the priorities of your services, like user permissions, virtual servers, security policies, and more.
## Core Services ⚙️
These are four core services within AWS:
### <u>Amazon Elastic Compute Cloud</u>
A resizable compute capacity service which allows users of the service to host websites across multiple datacenters. Scaling sites is allowed through load balancing, autoscaling, or even external databases.
### <u>Amazon Simple Storage Service</u>
A scalable and durable object storage infrastructure. This can be used to host static sites and deliver HTML, JavaScript, images, and videos for the site.
### <u>AWS Lambda</u>
A compute service meant to run code in response to events and automatically manages to compute resources for the service you are handling.
### <u>Amazon RDS</u>
The Amazon Relational Database Service is a relational database service made to automate and efficiently handle administrative database tasks, all while being secure and available. 
## Advantages ‼️
AWS being a service that has been around long enough to establish itself as a massive cloud provider, it has come with the following advantages:
1. **Flexible and easy to scale** - Due to the service's very own nature, it allows itself to be relatively easy to scale up as you grow your site. Thanks to its availability, it allows itself to scale up within traffic spikes. Not to mention, it has a rather broad platform support, allowing for more flexibility.
2. **Lower cost for setup** - AWS only charges you for your resources, so depending on the scale of your site, it can be relatively cheap to set up a service within AWS.
3. **Quick setup** - AWS has a massive range of services compared to other cloud providers, this allows for setup to be relatively quick to handle. This is mostly because, despite the massive amount of options you may have, usually there is one that could fit your very use case relatively quickly.
## Enterprise Use Cases 👥
A majority of use cases for AWS comes within the hosting of web applications or mobile applications. Due to how broad the services within AWS is, there is always something for said web or mobile application.

Another reason why enterprises may use AWS is due to its availability for backups. AWS as a cloud service has durable cloud storage, and it also has the option for automated failover configurations.

Another reason can also be for data analytics and AWS having a broader compatibility with systems. AWS being established rather early allows for more compatibility to be set in place, which is perfect in the context of big data and legacy systems. It also means that the service runs fast for handling massive amounts of data.

# Client Recommendations
The table above can be used as reference as to why said platforms are chosen. Other than that, let us see what our clients may be requesting.
## Client A – Startup Company
> A startup company wants to launch a new mobile application. Their budget is limited, but they expect rapid growth within the next few years.

### AWS
Due to the limited budget and expected rapid growth, AWS Amplify is highly recommended alongside Amazon DynamoDB and Amazon Cognito. These three services are capable of providing the basic infrastructure for the mobile application during startup. These services are low in cost until success is achieved, in which, by then, the company is able to scale up.
## Client B – University
>A university already uses:
>* Windows Server
>* Microsoft 365
>* Active Directory
>
>The university wants to migrate some services to the cloud.

### Azure
It is recommended that the university uses Microsoft Azure due to their connection with Microsoft products. Due to Microsoft products being ingrained within usage, Azure allows for a seamless integration for some of these services to migrate to the cloud. They are able to use Azure Files, Microsoft Entra ID, and Azure App Services for the basic infrastructure. Azure Virtual Machines can also be used if legacy systems are being used within the university.
## Client C – AI Research Company
>A research company develops Artificial Intelligence and Machine Learning applications that require highperformance computing. 

### GCP
GCP is immediately recommended for this research company for its connection with AI and ML. This is especially the case when they are handling Artificial Intelligence and Machine Learning, which requires a lot of data analysis. Cloud TPUs, Vertex AI, and Cloud Storage are part of the basic services they would need for getting started with handling something like this.
## Client D – Global E-Commerce Company 
>A multinational online shopping company serves customers around the world and requires highly available infrastructure with automatic scaling.

### AWS
AWS is a recommended choice for this considering the requirements being availability and scaling being a must. This is especially the case since the scale of this E-Commerce Company requires highly available infrastructure with automatic scaling. Amazon DynamoDB, AWS Artifact, and Amazon ECS are some of the services that could be used for this case.

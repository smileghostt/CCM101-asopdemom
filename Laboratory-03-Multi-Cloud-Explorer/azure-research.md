# Overview 🔍
Azure or Microsoft Azure is a cloud computing platform made by Microsoft made especially for environments that heavily rely on Microsoft products. It also presents itself as a choice for hybrid or multi-cloud architectures. It offers the usual services a cloud computing program may provide, with things like storage, compute, network, and the likes.
## Global Infrastructure 🌐
The global infrastructure for Azure spans within over 80 regions and contains over 500 datacenters. Most of these areas span within the US or throughout Europe, however, some of the regions are located within Asia. The availability zones have their own cooling systems and are fault-isolated. Plus, PoPs or points of presence lessens latency and adds security.
## Cloud Management Console 🎛️
The Azure Portal, which is the designated Cloud Management Console of this cloud computing service, provides a web-based, centralized interface allowing you to monitor your services and build them easily. Dashboards within Azure is rather customizable to your needs, and they provide role-based access control, billing analytics, and the Cloud Shell to run commands within.
## Core Services ⚙️
The following are four core services within Azure:
### Azure Virtual Machines
Azure VMs provides readily available, scalable Windows and Linux Virtual Machines. It can support just about anything from lightweight servers, to massive computes with plenty of data.
### Azure Files
Azure files is a serverless cloud file sharing service connected to Azure. This allows you to share files using SMB or NFS protocols.
### Azure SQL Database
A database engine based on Microsoft SQL Server. Azure SQL Database provides automatic scaling, backups, and threat detection
### Azure ExpressRoute
Expressroute provides secure, private cloud connections. This allows you to extend your network into the cloud without using the public internet.
## Advantages ‼️
The following are the three advantages of using Azure as your cloud computing platform:
1. **Synergy with Microsoft products** - If your work environment already uses Microsoft products heavily, Azure is relatively easy to use within the environment. It especially integrates itself within products like Visual Studio and Microsoft 365.
2. **Seamless Hybrid Cloud Experience** - Azure's services lean heavily on its capabilities with offering a seamless Hybrid Cloud experience. This allows it to work with on-premise data centers easily.
3.  **Heavy Compliance with Security** - Microsoft is known for its heavy compliance with security standards, not to mention having an entire infrastructure for handling threats. This allows Azure to have enterprise-grade protection.
## Enterprise Use Cases 👥
A lot of the use cases for Microsoft Azure boils down to its nature within Hybrid Cloud. It provides Hybrid Identity and Access Management, allowing you to add multiple walls of security to keep your services safe.

Azure allows for a smooth transition to a more modernized experience, keeping your services up to date. This is especially seen with the fact it is able to refactor legacy applications and SQL server databases into cloud microservices. This also means that warehousing data and handling business intelligence becomes easier to scale.

Lastly, due to Azure's priority on rigidity, disaster situations and backups are highly used. Azure allows for automatic backups and notes of geo-redundant storage tiers. This allows for services to run continuously despite infrastructure disruptions.

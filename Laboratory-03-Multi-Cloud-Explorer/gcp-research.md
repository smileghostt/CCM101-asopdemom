# Overview
GCP or Google Cloud Platform is a cloud platform made by Google. The cloud platform is known to be used internally for applications like Gmail and YouTube, whether partially or wholly. It is known for its power within analytics, machine learning, and containerization. This makes it a robust platform for some modern infrastructures.
## Global Infrastructure 🌐
The global infrastructure of GCP is concentrated. There are over 40 regions spread across the world and over 130 availability zones with a minimum of three per region. Not to mention, the infrastructure also runs within a massive line of private global networks, allowing the latency to lower.
## Cloud Management Console 🎛️
The Google Cloud Console presents with the projects currently running. Alongside this, there are graphs and other pieces of information regarding the services being hosted, allowing you to monitor your applications with ease. All of this works with the Cloud SDK and the Cloud Shell as well, just so you are able to do commands within the browser.
## Core Services ⚙️
### Google Kubernetes Engine
Kubernetes Clusters completely provided by Google. This service is meant to provide and allow you to create containerized applications automatically.
### Cloud Storage
A scalable cloud storage service meant for storing images, backups, and massive files. It allows automatic backups if ever needed.
### BigQuery
A serverless data warehouse for analytics. Capable of managine massive SQL queries at quick speeds.
### Virtual Private Cloud (VPC)
A private cloud that provides an isolated network environment for your application resources.
## Advantages ‼️
The following are the advantages of using GCP as your cloud computing platform:
1. **Commits to open-source foundations and container standards** - GCP minimizes vendor lock-in for open source foundations like Kubernetes. GCP also eases multi-cloud portability thanks to this.
2. **Good performance in global private networks** - GCP ensures public internet hops are kept to a minimum. This also allows GCP to ensure the private network performs well, keeping its speed and availability.
3. **Leads within data analytics and MLs** - GCP is especially known to handle massive amounts of data analytics and excels within machine learning pipelines.
## Enterprise Use Cases 👥
A lot of its enterprise use case comes within the handling of massive data analytics and machine learning. GCP is able to handle these analytics in real time, allowing for predictive modeling and live business intelligence. GCP also provides TPU clusters for AI machine learning.

This isn't the only thing GCP can be used for. GCP also does well for handling microservices and creating an architecture for these services. This cloud computing service also is decent with multi-cloud and hybrid integration.

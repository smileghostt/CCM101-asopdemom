# Mission Overview
The following mission involved handling observability and monitoring within an infrastructure. In this case, we are using docker as our process to understand how these infrastructures are monitored and observed.
# Objectives
The following objectives are as follows:
- Utilizing Linux's CLI in order to monitor information regarding the host's CPU, memory, and disk.
- Deploying a web container and tracking it's performance using Docker metrics.
- Generate web traffic for analysis.
- Extract logs for analysis.
- Essentially making reports with the following and expanding our portfolio further.
# Monitoring Commands Executed
- `free` - checks for system's overall memory.
- `fdisk` - checks for system's storage space.
- `top` - checks system health, overall activity, and processes within the system in real-time
- `docker logs` - prints out the logs of a specific containter.
- `docker stats` - similar to `top`, however this specifically is for docker containers.
# Skills Learned

The skills learned were mostly catered towards handling, managing, and observing containers. This provided the basics on dealing with logging and understanding the behavior of a container. All of this can help with troubleshooting.

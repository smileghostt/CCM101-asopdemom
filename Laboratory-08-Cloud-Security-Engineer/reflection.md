This lesson overall improved my understanding of firewalls! I believe I can use this within my future. Lets get started with answering the questions given to us within the mission.

A host-based firewall allows protection for a server even if the physical network perimeter is breached as it becomes the final line of defense for the server. Thanks to how it behaves, it ensures a filter is set up in order for attacks to be reduced. All of this is to say that firewalls are helpful to filter out attackers from legitimate connections.

Managing open ports is critical due to the fact these can act as entry points and vulnerable areas that allow you to get deeper into the server itself. These ports essentially dictate how vulnerable a system can be and how exposed the system overall is. You really need to manage these in order to ensure exploits and the likes barely happens at all, or else your system is in danger to attackers.

Wtihin a real enterprise environment, exposing a database port to the public internet is essentially just a way to expose the core to attacks and full system takeovers. This is already bad no matter what, as the public internet is not safe at all, and this is just a way to have every piece of data within the database either leaked and/or destroyed by people with unauthorized access willing to do some malicious stuff.

This mission overall made me aware of how servers can be compromised by poor security measures. Even adding a firewall allows for some safety measures to be set up, but a lack of maintenance means that eventually the system can become really insecure over time.

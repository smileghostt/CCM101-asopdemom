# The Principle of Least Privelege 👥
The principle of least privelege is a practice that ensures users, applications, and jobs only have the bare minimum permissions and data needed to do their job. This ensures that what is required is the only thing each part can do, reduces the amount of damage that can be done, and ensures security and integrity.
# Attack Surface 💥
Attack surface usually means the vulnerabilities where unauthorized users can  access data or comprimise the system. When applied to a virtual machine, this would include layers unique to virtualization aside from standard OS components within the guest environment.
# Default Deny Policy ❌
Denying all traffic is much safer than trying to block hackers individually as hackers can merely change their IP and still attack the network. This also lessens the margin for human error and ensures that the network isn't attacked often.

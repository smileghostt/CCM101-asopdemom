# Mission Overview 📜
For our mission objectives, your goal is to be able to:

- Differentiate Block, File, and Object storage.
- Deploy an S3-compatible Object Storage within Docker.
- Access a cloud service within a web interface using port forwarding.
- Create a storage bucket and upload objects.
- Document it and continue expanding on the GitHub Cloud Computing Portfolio.
# Objectives 📝
The first half of the objective is being able to create a comparison table to present one's capabilities on differentiating what Block, File, and Object storage does, what its best for, and what services provide those sorts of storage. The rest, however, focuses more on the creation of an object storage container alongside how to handle one. Essentially, successfully handle an object storage image within Docker.

# Tools Used 🧰
- **A web browser** - Can be any web browser. Mostly to access everything else here.
- **An internet connection** - Obviously.
- **KillerCoda** - Playground for Ubuntu.
- **Docker** - Open platform for deploying packages into containers.
- **Object storage image, specifically SILO** - Alternative to MinIO, runs similarly to MinIO. (Required due to MinIO having removed their DockerHub community edition images.)

# Skills Learned 🤓
The skills learned were mostly on handling Docker containers, especially Object Storage. There may be some knowledge obtained via how to document these, but for the most part its mostly on handling Docker and handling object storage itself plus seeing how it works.

The following is research on multiple types of cloud storage.
# Comparison Table

|  | Block Storage | File Storage | Object Storage |
|---|---|---|---|
| **Description** | Block storage is a type of cloud storage that stores data by segregating them into chunks and then storing these blocks as separate pieces with their own unique identifiers. | File storage is a type of cloud storage that, as its name suggest, organizes data into paths and into a file/folder-like structure akin to how the file manager within your PC works. | Object storage is a type of cloud storage that, rather than have a hierarchy or structure, leaves itself unstructured. Each item within the storage is kept as its own individual objects. |
| **Primary Use Case** | Allows data to be used for relational or transactional databases. Also eases use of data within high performance environments. | Collaboration and ease of use by familiar data structure. | Easy way to handle backup and unstructured data. |
| **Cloud Provider Example** | Google Persistent Disk | DropBox | Google Cloud Storage (GCS) |


# Is object storage the best for storing user-uploaded images?
Due to object storage being unstructured, it ends up being the best way to store user uploaded images. Part of this is because it manages to effortlessly unstructured media while being seamlessly useable within HTTP and yet be scalable.

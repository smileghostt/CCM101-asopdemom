The following is research on multiple types of cloud storage.

# Block Storage 🧊

## Description
Block storage is a type of cloud storage that stores data by segregating them into chunks and then storing these blocks as separate pieces with their own unique identifiers.

## Primary Use Case
Block storage allows for data to be used within relational databases or transactional databases. Most of this is because segregating data into chunks allow for it to be used within high performance environments without much latency attached. Essentially, block storage is quite efficient for said environments.

## Cloud Provider Example
Google Persistent Disk

# File Storage 🗃️

## Description
File storage is a type of cloud storage that, as its name suggest, organizes data into paths and into a file/folder-like structure akin to how the file manager within your PC works.

## Primary Use Case
The best use case for file storage has to be within storing data into a familiar format. Not only that, it also allows for data to be easily pulled from the server and to be used elsewhere. In team settings, it especially allows an easier way to collaborate with others.
## Cloud Provider Example
DropBox

# Object Storage 🧰

## Description
Object storage is a type of cloud storage that, rather than have a hierarchy or structure, leaves itself unstructured. Each item within the storage is kept as its own individual objects.

## Primary Use Case
Object storage allows for easy backup of data. It is mostly seen used on data backups or disaster recoveries. It also is great to use on big data and machine learning.

## Cloud Provider Example
Google Cloud Storage (GCS)

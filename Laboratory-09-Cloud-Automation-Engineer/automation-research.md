# Bash Script
A bash script is a plain text file containing a series of command executed by bash. ` #!/bin/bash` or shebang is meant to be an instruction telling the kernel to use the bash interpreter.

# Variables
Using variables instead of the full path allows for reusability and maintainability. This allows for the code to be reusable, flexible, and easier to read compared to constantly typing hardcoded full paths.

# Cron Job
Cron jobs in Linux are automated tasks that run through the cron daemon. This is essential for cloud operatoions as it allows for virtual machines and containers to run with as minimal human supervision as possible.

# Mission Overview
The scale of the job becomes larger, in order to proceed, it is a must to understand how to automate parts of your infrastructure. Using bash scripting and cron jobs, you must learn how to execute automation within the infrastructure.
# Objectives
- Understand bash scripting, including creating variables and basic commands.
- Use nano (a command line editor) to write and save scripts.
- Modify file permissions with `chmod`.
- Understand task scheduling annd the syntax of a crontab
- Document automation code and Cron job configs in markdown.
# Commands Executed
- `mkdir` - make a directory.
- `echo` - can be used to print text, display variables, or write/append text to a file.
- `nano` - third party command, can be switched to `vim` or your command line editor of choice. Command used to open a command-line text editor.
- `chmod` - change mode. An important command that is used to change the permission of files and directories. This can change the read, write, and execute access permissions.
- `ls` - lists files within the current directory.
    - the `-l` flag in this case is for the long listing format.
- `crontab` - tool used within the config file for scheduling tasks that run in the background.
    - the `-l` flag is used to specify to display a list of active tasks.
- `env` - short for environment. Used to manage the environment. Can be used to display the current environment or execute something within a custom environment.

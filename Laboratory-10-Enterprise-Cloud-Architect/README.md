# Mission Overview
There are no step-by-step instructions, the task being given was to create a proper, production-ready infrastructure by scratch. This is to be presented, and it is required to be functioning and ready for deployment.

This means that everything has to be built from scratch within a VM. Containers, security, and automation are all on the hands of us.
# Objectives
- Conceptualize an infrastructure.
- Create and configure a headless Ubuntu Server VM.
- Install and configure Docker.
- Deploy multi-containerized applications without any handholding, as well as ensuring containers have persistent volumes.
- Implement proper security measures and port handling.
- Automate operational tasks with cron jobs and bash scripts.
- Synthesize all technical documentation to a Github Portfolio.
- Demonstrate and defend the infrastructure.

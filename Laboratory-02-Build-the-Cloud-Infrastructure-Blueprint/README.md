# Cloud Infrastructure Components ☁️
## Compute
The compute of a cloud infrastructure involves things like virtual computers, which can correlate to CPU and RAM for example within the Linux environment in Killercoda. Within cloud services, this is usually the computing power within the software side.

## Storage
Storage within a cloud infrastructure dictates how much information can be stored within the cloud. This would correlate to drives within the Linux environment in Killercoda, and is just as important as the compute side of the infrastructure, as this allows for files to be stored without needing to stay wihtin a singular device.

## Networking
This one correlates more to the conection within the service. Network resources is especially important for the infrastructure despite how invisible it is, as it allows more people to be in contact with the services.

## Identity and Access Management
Identity and Access Management is essentially the security framework in cloud infrastructure. This allows for people with the right roles and permissions to see what they can only see or access, and restricts outsiders from unauthorized access or viewing.

# Linux Commands Executed 🗣️🔥
This is a list of the linux commands that have been used within the activity! There are a huge set of these, so I will try to do what I can remember!

- `cat`: short for concatenate. can be used to view, combine, or create text files
- `lsb_release`: linux standard base release. used to check the linux distribution
- `hostnamectl`: lists the hostname and information regarding the host, also used to change host name
- `hostname`: lets you view the host name, information regarding the host, or change it. flags like -I can specify what you want viewed
- `uname`: unix name, provides system information, especially needed when checking the kernel version
- `lscpu`: list CPU information. provides the architecture of the CPU
- `nproc`: lists number of CPU
- `free`: provides information regarding system memory and usage
- `df`: disk free, provides information regarding disk usage
- `ip`: used to view and manage IPs. `ip addr` specifically lists all networks and their respective addresses

> **REMEMBER!** plenty of these commands have their own respective flags, man files may provide more information regarding how to use these commands, and most commands do not go without one. It is always available to provide help

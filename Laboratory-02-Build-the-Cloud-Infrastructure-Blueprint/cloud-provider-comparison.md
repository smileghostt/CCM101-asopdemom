## Q&A ❓
1. Which cloud provider offers the broadest range of services? Explain your answer.
    - AWS provides the broadest range. Most of this is because AWS had an early start compared to most of the other providers while allowing it to develop a large range of services first before its competitors. This also means that it may have a lot more features going for it that other competitors may not have.
2. Which cloud platform would you recommend for an organization that primarily uses Microsoft products?
Why?
    - The use of Microsoft azume is a must here since the organization has established that they primarily use Microsoft's products. This is mostly because Azure is best used within spaces that heavily relies on Microsoft products.
3. Which platform is widely recognized for Artificial Intelligence (AI), Machine Learning (ML), and
Kubernetes services?
    - GCP is widely recognized for all three of these. This is mostly because it is heavily integrated within its services.
4. What similarities did you observe among the three cloud providers? 
    - All three of these are completely similar within their core services. They all can provide virtual servers, cloud storage, and even their business strategies seem mostly similar in their core.
